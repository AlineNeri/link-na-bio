# Aline Neri | Link na bio

Página responsiva com os principais canais de contato e o catálogo da loja Aline Neri.

## Arquivos

- `index.html`: estrutura e links da página.
- `style.css`: estilos, layout responsivo e animações.
- `img/logo-bio.jpg`: imagem da marca.

## Visualização local

Abra `index.html` em um navegador. As fontes e os ícones são carregados de serviços externos e precisam de conexão com a internet.

## Publicação no GitHub Pages

Nas configurações do repositório, abra **Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta raiz (`/`).
